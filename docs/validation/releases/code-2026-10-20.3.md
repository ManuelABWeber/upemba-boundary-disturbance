# Lossless compression for reviewer access

This release replaces `reports/fire_missingness_resolution/fire_missingness_bounds_500m.csv` with its gzip-compressed `.csv.gz` equivalent so the large ancillary audit table can be retrieved through the anonymous review service. Decompression reproduces every byte of the original CSV. All numerical data, model results and analysis specifications are unchanged. Standard gzip tools can decompress the file; R `data.table::fread()` and Python `pandas.read_csv()` can read the compressed file directly.

This follows the metadata-only patch in code-2026-10-20.2. No manuscript or submission documents are included.
