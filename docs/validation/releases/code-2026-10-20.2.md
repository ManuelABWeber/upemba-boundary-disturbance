# Reviewer-access metadata patch

This release preserves all analysis data, coefficients, model specifications and sensitivity outputs from code-2026-10-20.1. It replaces a local Windows account name in saved package-session metadata with a neutral placeholder. Native R verification confirms that every saved model and the specification table are identical, and the session metadata differs only in the replaced library-path strings. The agricultural driver also removes identifying local-library paths when saving future session metadata.

This patch supports anonymous reviewer access. It contains no manuscript or submission documents and does not refit any model.
