# Additional dependence checks release validation

This release adds supplementary dependence analyses to September public commit 5a551cd. It retains the original primary results and the historical R environment. The current manuscript, supplementary Word document, submission forms, private historical documents and local package libraries are excluded. New inputs contain environmental cell histories and geographic-block counts, with source-raster hashes and a documented extraction path.

The portable preparation script reproduces all 1,936 original outcome/boundary/landscape/year/side count-and-denominator pairs. All eight regenerated geographic-block archives are array-identical to the original assessment inputs. Rerunning tree_checks.py reproduces all eighteen tree-loss draw archives, encompassing 359,962 model calculations across the reported and forest-only populations. The portable fire temporal, small-sample temporal, independent-estimator, optimizer-cross-check and residual-diagnostic scripts also run successfully. All twenty-five regenerated numerical CSVs match the retained tables exactly, with maximum absolute numeric difference zero. portable_validation.json lists the compared files; the comparison tolerances are recorded there.

The retained-draw audit checks 27 final runs, including all 18,981 accepted fire bootstrap fits, their replicate identities, analytic gradients, positive Hessians and recomputed percentile intervals. The original fire bootstrap fits were not all rerun merely to package this release. Independent R estimates reproduce the retained tree-loss coefficients and HC3 standard errors at all eleven boundaries. Fire estimates match retained primary values within 0.000001 log-odds units. Ten bounded-optimizer checks agree within 0.000002. Earlier pilot output is excluded from the published sensitivity package.

The existing repository checks also pass: compare_frozen_results.R reports zero failures across 23 scalar targets, 18 classifications and three primary totals; test_agriculture_followup.R passes the calendar-follow-up, baseline, later-crossing and missing-data checks; check_final_reconciliation.R passes the corrected counts, primary-sample, coverage and denominator checks. No numerical acceptance threshold or frozen expected result was relaxed.

The new Python drivers compile and the R drivers parse. The two numerical figures were regenerated and visually inspected. R-package-versions.csv, software_environment.json and the retained sessionInfo files describe the tested environment. The historical top-level renv.lock remains unchanged. New computation defaults to an ignored working directory and does not overwrite the committed inputs or retained sensitivity results.

The input release manifest records the new package's file sizes and SHA-256 hashes. verify_release.py checks them, independently compares each block configuration with the retained count surfaces, audits every accepted draw and recomputes the paired-profile, endpoint-Monte-Carlo and legal-versus-outer interval summaries in a temporary working folder. The scientific point estimates, event definitions and chronology remain those of the primary analysis.

A clean export containing only the staged public repository files also passes verify_release.py and rebuilds all 1,936 count pairs. A three-draw fire bootstrap smoke test runs from that export and reproduces all nine corresponding retained profile contrasts exactly. This checks the packaged fire driver and its inputs without relying on the original workspace's analysis files. Local package libraries supply only the explicitly documented software dependencies.
