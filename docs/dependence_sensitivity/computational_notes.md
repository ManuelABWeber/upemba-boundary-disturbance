# Computational notes

The first main fire process completed all six configurations and wrote every expected draw, diagnostic and interval file. Its trailing session-information command then encountered a parse error because the driver file had been edited while the already-parsed bootstrap loop was running, to add the separate long-range configuration. The error occurred after the numerical outputs were saved. The current driver is parsed independently and the computational environment is recorded separately in sessionInfo_fire.txt. Numerical completeness is checked from replicate identities, expected configurations, fit diagnostics and recomputed quantiles rather than inferred from the exit code. The same bookkeeping issue also affected the outer process. Both runs passed the complete post-run audit; no numerical draws were lost.

The package clubSandwich 0.7.0 was installed from the official CRAN source into the task-local R library for the added small-sample temporal sensitivity. No global R library was changed.

The earlier pilot sampled landscape groups separately within geographic blocks and used a noisy finite-difference gradient check. The present analysis jointly resamples geographic blocks across groups and validates all fire fits with two independent analytic derivative calculations. Earlier pilot intervals are not used in the report.

The 40 km tree-loss run was increased from 4,999 to 19,999 resamples because the militia-centred upper endpoint was close to zero. Its Monte Carlo endpoint uncertainty is explicitly reported. The short calendar record also motivated the CR2/Satterthwaite checks using one-, two- and three-year clusters at all origins. These sensitivity extensions are disclosed and do not change the original point estimands.

An additional optimiser cross-check found that unrestricted BFGS can explore numerically invalid, extreme beta-binomial precision values and return a non-positive Hessian. Those alternative fits were not used. L-BFGS-B with broad coefficient bounds and log-precision between -10 and 12 reproduced ten checked bootstrap contrasts to within 0.000002, with interior optima, positive Hessians and convergence code zero. Its stopping tolerance was tightened from the default to factr=1e4; requesting factr=1 produced roundoff-related line-search warnings despite close agreement. The primary bootstrap uses the separately validated Newton-refined estimates and strict analytic-gradient criterion throughout. Raw cross-check diagnostics are retained.
