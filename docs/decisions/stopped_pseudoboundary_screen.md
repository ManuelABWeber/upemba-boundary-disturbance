# Stopped Pseudo-Boundary Screen

The original symmetric inner/outer offset-boundary screen stopped before outcome fitting because fewer than three valid inner pseudo-boundaries remained. Only -15 km and -20 km retained enough support. No outcome models were fitted. The approved revised design uses +20/+40/+60 km as the primary spaced outer set, +15 through +60 km as a dense outer gradient, and -15/-20 km as limited inner checks. The stopped script remains only in the frozen development archive.
