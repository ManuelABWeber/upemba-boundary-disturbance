# Upemba boundary disturbance code and research outputs

This repository contains analysis code, derived environmental inputs and retained results for comparisons of fire, tree-cover loss and agricultural expansion across Upemba National Park’s legal boundary during 2001–2022. An independently reconstructed chronology distinguishes fragmented, militia-centred and park-centred territorial control. These observational comparisons do not establish a causal effect of protection.

The current submission code release is [code-2026-10-20.2](https://github.com/ManuelABWeber/upemba-boundary-disturbance/releases/tag/code-2026-10-20.2). It includes the additional spatial and temporal dependence checks and a curated repository without manuscript files, supplementary-document drafts, cover letters or editorial replacements. The code and research results are the public submission materials. Paper documents are managed separately. The superseded releases are retired as part of the history cleanup; use this version for submission.

Start with [RUN_ANALYSIS.md](RUN_ANALYSIS.md). The [results index](docs/RESULTS_INDEX.md) identifies the current source for each analysis. The [analysis specification](docs/decisions/authoritative_analysis_specification.md) states the event definitions and comparison design. [CITATION.cff](CITATION.cff) identifies the citable version.

The primary 10 km corridor contains 42,554 cells, 508,320 burned cell-years, 519 tree-cover-loss events and 518 agricultural first crossings. The corrected agricultural persistence analysis contains 414 events with candidate years 2001–2019. The primary point estimates, event definitions and chronology are preserved. The forest-only tree-loss denominator remains a separately labelled sensitivity.

The additional [dependence module](analysis/dependence_sensitivity/README.md) contains portable Python/R drivers. Its committed environmental histories and block counts support reproduction of the additional statistical checks without the former analysis workspace. All accepted resampling draws, numerical diagnostics, interval summaries and two figures are in outputs/dependence_sensitivity/. The [methods and table map](docs/dependence_sensitivity/methods_and_results.md) links the new supplementary results to those files.

The four top-level analysis_*_dev/ directories are frozen analytical snapshots, retained because current verification and figure code read their numerical tables. They are not temporary development folders. [Their index](reports/repository/ANALYTICAL_OUTPUTS.md) explains their roles. Corrected agricultural, post-event and seasonal analyses have a single canonical location in outputs/final_reconciliation/. data/governance_profiles/ contains the wide-form chronology; evidence/ contains coded source metadata. Unique measurement and model-validation reports remain as scientific provenance.

The [cleanup record](docs/validation/repository_cleanup.md) and [file manifest](docs/cleanup_manifest.csv) document retired files and consolidated copies. The [release manifest](RELEASE_MANIFEST.json) checksums the current package. Tests verify the retained primary results, corrected agricultural logic and counts, sensitivity draws, and absence of manuscript files or exact duplicate files.

A complete upstream reconstruction still requires the external raster/spatial inputs recorded in data/manifests/ and the original environment in renv.lock. The new sensitivity analyses can run from the committed derived inputs. Original historical documents, raw imagery, private operational evidence, credentials and local package libraries are excluded. See [data documentation](data/README.md) and [third-party notices](THIRD_PARTY_NOTICES.md).
