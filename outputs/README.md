# Retained research outputs

outputs/final_robustness/ retains primary estimates, matched chronology/influence and alternative-boundary numerical diagnostics. outputs/final_reconciliation/ is the canonical corrected agricultural and post-event result set, including static Hansen overlap and seasonal rainfall/fire data. outputs/dependence_sensitivity/ contains the additional spatial/temporal sensitivity draws, diagnostics, summaries and figures.

Paper manuscripts, supplementary-document drafts, cover letters, editorial replacements and obsolete presentation layouts are excluded. Generated validation and figure scratch files go under the ignored outputs/_validation/ directory. The [results index](../docs/RESULTS_INDEX.md) identifies current sources. Tests verify that the public tree contains no manuscript files or exact duplicate files.
