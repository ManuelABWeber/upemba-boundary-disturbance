# Public repository scope

The current tree and curated release contain analysis code, derived environmental inputs, coded source metadata, numerical results, figures and scientific validation records. They contain no manuscript or supplementary-document files, draft cover letters, highlights, editorial replacement collections or document-building scripts. The public-tree test enforces this scope.

Original historical documents, personal correspondence, informant details, patrol and law-enforcement records, precise security-event records, credentials, raw downloads, local software libraries and local configuration are excluded. Environmental cell coordinates identify the study grid and satellite-derived observations, not operational or personal records. Source products and third-party software retain their own terms.

The cleanup consolidates redundant copies while preserving the scientific results. Published branch history is rewritten to remove manuscript-bearing paths, and superseded releases and merged branches are retired. GitHub may retain old objects through read-only pull-request references or cached views. These and other people's clones/forks require separate action and are not covered by a claim that the current release contains no manuscript. See the [cleanup record](docs/validation/repository_cleanup.md).
